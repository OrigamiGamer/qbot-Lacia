# Lacia
A chat bot based on py package `botpy`.

# Packages Required
| Package                                           | Version | Description                      |
| ------------------------------------------------- | ------- | -------------------------------- |
| [Python](https://www.python.org/downloads)        | 3.14+   | Virtual environment recommended. |
| [botpy](https://github.com/tencent-connect/botpy) | 1.2.1   | Official QBot Python SDK.        |
